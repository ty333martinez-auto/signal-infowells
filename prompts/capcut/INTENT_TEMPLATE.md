## Execution instructions
1. Inspect available source assets before editing; do not claim access to files you cannot see.
2. Preserve the intended message and all supplied factual claims. Do not add unsupported claims.
3. Create the timeline and edits requested; use restrained, purposeful pacing and transitions.
4. Ensure captions are legible and synchronized if captions are requested.
5. Check aspect ratio, duration, audio levels, and export settings against the intent.
6. If a missing asset or answer blocks execution, ask for it instead of fabricating it.
7. Export the requested deliverable and report the actual output filename, format, and any unmet acceptance check.
